# Contributing

## Scope

Contributions must improve shared contracts, adapters, evaluation, documentation,
or rights-cleared examples for thermal AI research. Do not submit confidential,
unpublished, student-identifying, sponsor-restricted, export-controlled, or
otherwise uncleared materials.

## Before opening a contribution

1. Use the data-rights manifest template for every data, weight, figure, or
   derived artifact.
2. Preserve raw data; submit code, metadata, approved derived artifacts, or
   download instructions instead where appropriate.
3. State units, time bases, synchronization, evidence class, operating
   conditions, and uncertainty relevant to the contribution.
4. For ML results, use condition-level holdouts and include simple baselines,
   calibration or uncertainty information, and inspected failure cases.

## Pull requests

Keep pull requests scoped and include tests for contract or evaluation changes.
Do not claim external validation, field deployment, or a digital twin unless the
supporting evidence is documented in the contribution.
